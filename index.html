Tìm hiểu và ứng dụng Bootstrap trong thiết kế giao diện Web Responsive

Hệ thống học tập trực quan minh họa kiến trúc Lưới 12 cột, Thành phần giao diện và Lớp tiện ích của Bootstrap 5.3 trên Máy tính, Máy tính bảng và Điện thoại di động.

Bắt đầu bài học Xem bảng so sánh

1. Thiết kế Web Đáp ứng và Mục đích sử dụng Bootstrap

Thiết kế Web Đáp ứng là phương pháp xây dựng một mã nguồn trang web duy nhất có khả năng tự động co giãn và sắp xếp lại bố cục hiển thị tối ưu trên mọi kích thước màn hình.

Mục đích sử dụng Bootstrap: Chuẩn hóa quy ước định kiểu giao diện trong nhóm phát triển, đảm bảo tương thích đa thiết bị và rút ngắn từ 60% đến 70% thời gian viết mã CSS thủ công.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
Ba trụ cột của Bootstrap 5.3
  • Grid System: Lưới Flexbox 12 cột với 6 mức điểm ngắt linh hoạt.
  • Components: Hơn 20 khối giao diện tương tác qua thuộc tính data-bs-*.
  • Utilities & Dark Mode: Lớp tiện ích nguyên tử và chế độ Sáng/Tối nguyên bản.

2. Tiến trình phát triển từ Bootstrap 1 đến Bootstrap 5.3

Phiên bản Năm Cải tiến kiến trúc trọng tâm
Bootstrap 1 & 2 2011–2012 Khởi đầu chuẩn hóa Typography, nút bấm và bổ sung lưới 12 cột .row-fluid theo hướng Desktop-First.
Bootstrap 3 2013 Chuyển sang triết lý Mobile-First và Flat Design; lưới 4 mức điểm ngắt dựa trên CSS Float.
Bootstrap 4 2018 Thay thế Float bằng CSS Flexbox, chuyển sang SASS, đơn vị rem, thành phần Card và 5 mức điểm ngắt.
Bootstrap 5.3 2021–nay Loại bỏ hoàn toàn jQuery, dùng Vanilla JS ES6, thêm mức xxl, lớp .g-*, Utility API và Native Dark Mode.
