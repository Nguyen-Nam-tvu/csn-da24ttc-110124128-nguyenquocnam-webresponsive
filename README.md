## 2. Mục tiêu đề tài
- Nắm vững cấu trúc, nguyên lý hoạt động của **Bootstrap 5** (Grid System, Components, Utility Classes).
- Thiết kế và xây dựng website hoàn chỉnh, nhiều trang, hiển thị tương thích (Responsive) trên 3 nhóm thiết bị: Máy tính (Desktop >= 1024px), Máy tính bảng (Tablet 768px - 1023px) và Điện thoại (Mobile < 768px).
- Đánh giá ưu điểm, hạn chế của Bootstrap 5 so với việc viết CSS thuần.

## 3. Công nghệ và công cụ sử dụng
- **Ngôn ngữ & Framework:** HTML5, CSS3, Bootstrap 5 (CDN), Bootstrap Icons.
- **Công cụ phát triển:** Visual Studio Code (Live Server), Git & GitHub.
- **Trình duyệt kiểm thử:** Google Chrome, Microsoft Edge, Mozilla Firefox (DevTools).

## 4. Cấu trúc thư mục dự án
- `/progress-report`: Lưu trữ các file Báo cáo tiến độ hàng tuần.
- `/docs`: Lưu trữ Đề cương chi tiết, tài liệu tổng hợp lý thuyết và báo cáo tổng kết.
- `/src`: Lưu trữ mã nguồn các ví dụ thực nghiệm và website minh họa.
