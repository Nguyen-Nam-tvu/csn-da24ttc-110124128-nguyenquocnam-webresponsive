Utility Classes (Lớp tiện ích)

Lý thuyết

1.1. Utility Class là gì?

Utility Class là các lớp CSS đơn năng, kích thước nhỏ (mỗi class chỉ làm đúng một việc: canh lề, đổi màu, ẩn/hiện...), giúp lập trình viên tùy biến giao diện trực tiếp trên thẻ HTML mà không cần viết file CSS riêng.

Đây chính là điểm khác biệt lớn của Bootstrap so với việc viết CSS thuần: thay vì đặt tên class rồi viết rule CSS, ta ghép nhiều utility class có sẵn lại với nhau.

1.2. Bảng khoảng cách (Spacing)

Cú pháp chung: {thuộc tính}{hướng}-{kích thước}, ví dụ mt-3 = margin-top mức 3.

1.3. Nhóm utility phổ biến khác

  • Màu sắc: text-primary, bg-success, border-danger.
  • Hiển thị (Display): d-none, d-md-block — ẩn/hiện theo breakpoint.
  • Flexbox: d-flex, justify-content-*, align-items-*.
  • Văn bản: text-center, fw-bold, fst-italic, text-truncate.

2.3. Flexbox: Sắp xếp linh hoạt

Ba khối dưới đây dùng d-flex justify-content-between để tự căn đều khoảng cách:

Mục 1 Mục 2 Mục 3
<div class="d-flex justify-content-between">...</div>

2.4. Hiển thị theo breakpoint (Responsive Display)

Bạn đang xem trên màn hình nhỏ hơn md — dòng này chỉ hiện khi màn hình < 768px (d-block d-md-none).

Bạn đang xem trên màn hình từ md trở lên — dòng này chỉ hiện khi màn hình ≥ 768px (d-none d-md-block). Hãy thử thu nhỏ trình duyệt để thấy dòng còn lại xuất hiện.
