1. Ưu điểm rút ngắn thời gian thiết kế

Tại sao Bootstrap giúp tối ưu tiến độ dự án?
  • Không phải viết lại CSS cơ bản: Các class tiện ích căn lề, font chữ, đổ bóng đều được định danh chuẩn.
  • Thân thiện đa thiết bị: Cơ chế Grid tự giải quyết bài toán Responsive phức tạp trên nhiều thiết bị.
  • Dễ bảo trì và mở rộng: Mã nguồn chuẩn hóa giúp sinh viên và nhóm lập trình dễ đọc hiểu và nâng cấp.
  • Cộng đồng lớn: Tài liệu chính thức đầy đủ, dễ tìm hướng dẫn khi gặp lỗi.

2. Một số hạn chế cần lưu ý

  • Giao diện dễ trùng lặp: Nếu không tùy biến, các trang web dùng Bootstrap thường có "cảm giác" giống nhau.
  • Dung lượng file CSS/JS: Nếu nhúng toàn bộ thư viện mà chỉ dùng một phần nhỏ, trang sẽ nặng hơn cần thiết.
  • Cần học quy ước class: Người mới phải làm quen với hệ thống đặt tên class riêng của Bootstrap.
  • Khó tùy biến sâu: Thiết kế khác biệt hoàn toàn so với mặc định đòi hỏi ghi đè CSS khá nhiều.
