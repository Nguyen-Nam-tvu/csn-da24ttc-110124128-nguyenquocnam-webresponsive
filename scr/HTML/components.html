Các thành phần giao diện (Components)

Lý thuyết

1.1. Component là gì?

Component là các khối giao diện dựng sẵn, đóng gói cả CSS lẫn hành vi JavaScript (thông qua thuộc tính data-bs-*), giúp lập trình viên chỉ cần gắn đúng class HTML mà không cần tự viết logic JS.

Các component trong Bootstrap có thể chia thành 4 nhóm chính:

Điều hướng

Navbar, Breadcrumb, Pagination, Tabs

Nội dung

Card, List Group, Accordion, Carousel

Phản hồi

Alert, Modal, Toast, Spinner

Biểu mẫu

Form Control, Input Group, Validation

Thực hành

2.1. Card & Button

Thanh điều hướng

Hỗ trợ menu co giãn, nút gập mở (Toggler) chuẩn di động mà không cần tự viết JS.

Component: Navbar
Hộp thoại nổi

Hiển thị bảng thông báo, popup xác nhận ngay trên trang mà không bị chuyển hướng.

Component: Modal
Thẻ & Nút tương tác

Card đóng gói dữ liệu trực quan kèm các nút bấm tích hợp sẵn bảng màu hiện đại.

Component: Cards & Buttons

Các biến thể màu của Button (.btn-*):

<button class="btn btn-primary">Primary</button>

2.2. Modal (Hộp thoại)

Nhấn nút bên dưới để xem một Modal thật, chỉ dùng thuộc tính data-bs-toggle, không cần viết JavaScript riêng:

<button data-bs-toggle="modal" data-bs-target="#demoModal">Mở</button>
<div class="modal" id="demoModal">...</div>

2.3. Accordion (Xếp lớp)

Chia màn hình thành 12 cột dựa trên Flexbox, tự động responsive theo breakpoint.

Không, chỉ cần nhúng file Bootstrap Bundle JS và dùng đúng các thuộc tính data-bs-*.
