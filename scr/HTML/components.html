1. Cơ chế kích hoạt Component qua thuộc tính data-bs-*

Các thành phần giao diện của Bootstrap 5.3 kết hợp định kiểu CSS với kịch bản JavaScript ES6 thuần. Lập trình viên kích hoạt hiệu ứng trực tiếp bằng thuộc tính HTML5 data-bs-toggle và data-bs-target mà không cần viết hàm JavaScript thủ công.

1. Điều hướng
Navbar, Offcanvas, Tabs, Breadcrumb
2. Nội dung
Card, Accordion, Carousel, List Group
3. Phản hồi
Alert, Modal, Toast, Progress, Badge
4. Biểu mẫu
Buttons, Input Group, Floating Labels

Khối giao diện linh hoạt dùng để trình bày bài viết, sản phẩm hoặc hồ sơ sinh viên.

Tiền tố bs tạo không gian tên riêng biệt giúp tránh xung đột thuộc tính khi tích hợp Bootstrap chung với các thư viện JavaScript khác.

Modal hiển thị hộp thoại ở chính giữa màn hình cho các xác nhận quan trọng, còn Offcanvas trượt từ cạnh màn hình để làm thanh thực đơn di động.
